# 🛠 Learning Journal – Spring Boot API

Dies ist mein erstes größeres Backend-Projekt im Rahmen meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung.  
Ziel war es, ein einfaches REST-API-basiertes System mit Spring Boot zu entwickeln – kein perfektes Ergebnis, aber ein wichtiger Lernschritt.

## 🎯 Ziel des Projekts
Ein digitales Learning-Journal mit folgenden Funktionen:
- Einträge erstellen, bearbeiten und löschen
- Tags für inhaltliche Strukturierung
- Benutzerregistrierung und einfache Authentifizierung
- REST-API-Schnittstelle zur Interaktion mit dem System

## ⚙️ Verwendete Technologien
- Java 17  
- Spring Boot  
- Spring Security  
- JPA / Hibernate  
- PostgreSQL (lokal oder in Docker)

## 🚧 Aktueller Stand
- Erste Version der API ist lauffähig
- Keine ausgefeilte Fehlerbehandlung oder Validierung – Fokus lag auf dem Verstehen der Grundlagen

## 📚 Gelernt auf dem Weg
- Aufbau und Strukturierung eines Spring Boot-Projekts
- Erstellen von REST-Endpunkten (CRUD)
- Umgang mit DTOs und Entitäten
- Einstieg in Authentifizierung 
- Nutzung von JPA für Datenpersistenz

## 📝 Nächste Schritte (optional)
- Frontend-Anbindung (z. B. mit React)
- Bessere Fehlerbehandlung und Validierung
- Rollen & Berechtigungen
- Testabdeckung
